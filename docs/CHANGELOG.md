## [Unreleased]

## [1.2.0] - 2026-07-28

### 修正
- 帳票用に事前起動した Excel に利用者が開いたファイルが相乗りし、空（真っ白）の Excel ウィンドウが出る問題を修正（待機中は描画停止・警告抑止を解除しておく／相乗りされている Excel は使い回さず終了もしない／帳票生成に失敗してブックが無い場合は表示せず終了する）
- アプリ終了時に、相乗りしていた利用者のブックを警告なしに閉じてしまう可能性があったのを修正

### 変更
- 手術記録検索・サマリ検索の Excel／csv 出力で毎回表示していた出力列の選択画面を廃止し、設定ボタンで保存した内容を無確認で適用するようにした（設定していない場合は全列を出力する。検査結果検索は出力列が選択した検査によって変わるため従来どおり出力時に選択する）
- Excel の事前起動をアプリ起動時から手術記録画面を開いた時に変更し、未使用のまま10分経過したら自動終了するようにした（常駐時間を短縮して相乗りされる機会を減らす）

### 追加
- 手術記録検索に「出力列設定」「サマリー列設定」ボタン、サマリ検索に「列設定」ボタンを追加（出力する列を事前に設定しておけるようにした）
- `EyeDataSettings.ini` に `[EXCEL_SETTINGS] EXCEL_WARMUP` を追加（0 で Excel の事前起動を無効化できる）

### 削除
- 患者台帳の「伝達」ボタンと伝達情報機能を削除（電子カルテ本体スキーマ `D_KARTE_MEMO` への書き込みが無くなった。伝達情報の閲覧・入力は電子カルテ本体側で行う）

### 変更
- 患者台帳の上段ボタン（家族／禁忌／手術予約／Inno／Grapa／PDF）を伝達ボタンの削除分だけ左に詰めた

## [1.1.0] - 2026-07-04

### 追加
- エクスポート画面に「患者（患者マスタ）」を追加（電子カルテ移行時の患者マスタ移行のバックアップ用。EYE系全テーブルに登場する PATIENT_ID の基本情報を出力）
- エクスポート画面に「手術予約（EYE_OPE）」を追加（手術記録エクスポートに含まれない記録未作成の予約も含め全件出力）
- エクスポートの出力文字コードに UTF-8（BOM付き）オプションを追加（既定は従来どおり Shift-JIS）
- エクスポート完了時に件数照合用マニフェスト（対象・ファイル名・件数・出力日時）を出力

### 修正
- 手術記録・サマリーCSVの各行末に余分な空カラム（末尾カンマ）が出力されていたのを修正
- サマリーCSVで項目値に半角スペースが2つ以上含まれる場合に3トークン目以降が欠落していたのを修正
- 手術記録・検査CSVから常時空のPDF関連カラム（PDF_SAVE / PDF_DATE / PDF_TIME）を削除
