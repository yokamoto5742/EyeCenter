# 紹介状の宛先表示の仕組み

患者台帳（`FormPat`）の画面上部、禁忌ボタンと手術予約ボタンの間にある淡黄色の欄（`IntroBox`）の説明です。
1.5.8（2026-10-05）で復活させました（2026-07-02 のリファクタリングで一度削除）。

## 画面上の動作

| 操作 | 動作 |
|---|---|
| 患者を開く・切り替える | 眼科が差し出した返事のうち最新の 1 件の宛先を「病院名 宛先科 宛先医師 先生」と表示する。該当が無ければ空欄 |
| 欄をダブルクリック | その患者の紹介状すべてを日付の新しい順に一覧表示する（`FormString1` ダイアログ） |

欄は読み取り専用で、このアプリから紹介状を登録・変更することはありません（電子カルテ側のデータを読むだけ）。

## 構成

| 場所 | 役割 |
|---|---|
| `FormPat.Designer.cs` の `IntroBox` | 表示欄（TextBox、位置 530,6 / 幅 190 / 読み取り専用 / 左上固定） |
| `FormPat.cs` の患者読み込み処理（禁忌情報取得の直後） | 宛先 1 件を選んで欄に表示する |
| `FormPat.cs` の `IntroBox_DoubleClick` | 過去の紹介状の一覧を組み立てて表示する |
| MedicalLibrary の `Entity/Intro.cs`（`Intro.GetList`） | DB から紹介状を取得する |

`Intro` は隣接プロジェクト MedicalLibrary にあるため、`EyeData.exe` と `MedicalLibrary.dll` はセットで配置します。

## データの取得（`Intro.GetList(患者ID)`）

新旧 2 つのテーブルを両方読み、1 つのリストにまとめて日付の降順に並べます。

| | 新システム | 旧システム |
|---|---|---|
| テーブル | `PATIENTINTRODUCTION` | `INTRODUCTION` |
| 接続 | `DB.Db3`（患者マスタ側） | `DB.Db2`（眼科DB側） |
| 患者ID | `PATIENTID` | `PATIENT_ID` |
| 種別 | `KIND`（文字列。「紹介」「返事」「依頼」で始まる） | `INTRO_KIND`（コード 1～6） |
| 日付 | `CREATEDATE` | `INTRO_DATE` |
| 宛先（病院・科・医師） | `DESTNAME` / `DESTDEPARTMENTNAME` / `DESTDOCTORNAME` | `HOSPITAL` / `DEPT_TO` / `DOCTOR_TO` |
| 差出科 | `FROMDEPARTMENTID` | `DEPT_FROM`（先頭の 0 を除いて使う。`07` → `7`） |
| 差出医師 | `FROMDOCTORNAME`（氏名） | `DOCTOR_FROM`（コード。`Dict.DoctorDict` で氏名に変換） |
| 除外条件 | `ARCHIVESTATE = 9` | `DELETE_FLAG = 1` |

- 新システムのテーブルは所有者（スキーマ）が環境によって異なるため、`dba_tables` で所有者を調べてから `所有者.PATIENTINTRODUCTION` を読みます。所有者は起動後の初回だけ調べて保持します（患者を開くたびには問い合わせません）。テーブルが無い環境では新システム分を読み飛ばします。
- どちらのテーブルも `schema/` の出力対象（`EYE_*` 9 テーブル）には含まれません。電子カルテ側のテーブルです。

## 種別コード

| コード | 意味 | 新システムの `KIND` からの変換 |
|---|---|---|
| 1 | 紹介 | 「紹介」で始まる |
| 2 | 返事（眼科） | 「返事」で始まる |
| 3 | 依頼 | 「依頼」で始まる |
| 4 | 返信Fax | （旧システムのみ） |
| 5 | 返事（途中） | （旧システムのみ） |
| 6 | 返事（最終） | （旧システムのみ） |

## 宛先欄に表示する 1 件の選び方

日付の新しい順に見ていき、次の両方を満たす最初の 1 件を表示します。

1. 種別が返事（コード 2・5・6）
2. 差出科コードが `7`（眼科）

つまり「眼科から出した返事の最新の宛先」です。他科が出した紹介状や、眼科が出した紹介・依頼は欄には出ません（ダブルクリックの一覧には出ます）。

## 一覧（ダブルクリック）の書式

1 件につき 1 行で、種別や差出科による絞り込みはしません。

```
2026/09/01 返事（眼科）　新テスト総合病院 眼科 新井 花子 先生（差出人　眼 山本 太郎）
```

差出人の科名は `Dict.DeptDict` の略称（`ShortName`）です。辞書に無い科コードは空欄になります。

## 注意点

- テーブルが存在しない、または `dba_tables` を参照する権限が無い場合は例外になり、患者台帳が開けなくなります（握りつぶしていません）。新しい環境に配置したら、最初に患者台帳を 1 件開いて確認してください。
- 患者を開くたびに DB への問い合わせが 2 本（新・旧）増えます。
- 欄は幅 190px 固定です。長い宛先は欄内でスクロールして読むか、ダブルクリックの一覧で確認します。
- ローカルのテストDBには確認用として `MEDB.PATIENTINTRODUCTION` を作成してあります（コードが読む列だけの仮の定義で、本番の定義とは一致しない可能性があります）。
